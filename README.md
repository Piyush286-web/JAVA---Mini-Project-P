# Online Student Management System (Spring + Hibernate)

## 🧾 Overview
Mini project demonstrating **Spring Dependency Injection (DI)**, **Hibernate ORM**, transaction handling for fee/payment, and **CRUD operations** for students.

---

## 📂 Structure
- `src/main/java/com/example/controller/` — all Java files (entities, dao, service, config, main)
- `src/main/resources/` — configuration files (hibernate.cfg.xml)
- `pom.xml` — Maven build file
- `.gitignore` — ignore target folders and credentials

---

## ⚙️ Setup (Local)

1. Install **Java JDK 8+** and **Maven**
2. Install & start **MySQL**, then create a database:
   ```sql
